# TikTokライバー向け 税金・国保・親の扶養 一撃診断

2025年・2026年の配信収入をもとに、税金、国民健康保険、年金、親の扶養への影響を概算するスマートフォン向けアプリです。日付と金額を記録できる台帳も使えます。

**公開ページ： [https://atatakeisi.github.io/Rust-TAX/](https://atatakeisi.github.io/Rust-TAX/)**

## 使い方

1. 公開ページを開き、マイクボタンから「20歳、去年50万、今年250万、経費30万」のように話します。マイクの使用を求められたら許可してください。例文ボタンや認識テキスト欄への直接入力も使えます。
2. 金額を調整する場合は、マイクの下の「手入力用」を開き、2025年・2026年の振込額と経費をスライダーまたは「−／＋」ボタンで設定します。2025年の開始月や申告状況もここで設定できます。
3. 「身バレ防止プロフィール選択」で年齢区分と給与の有無を選びます。給与がある場合は年間給与額を設定します。
4. 診断結果で白色・青色申告を切り替え、税金や国保、手残り、積立額、親の扶養への影響を確認します。詳細欄には年度別の内訳やアクションが表示されます。「スクショ1画面」や「LINEコピー」も利用できます。

音声認識が使えない場合は、画面の案内に従って端末のキーボードの音声入力を使うか、テキスト欄やスライダーで入力してください。音声認識の対応状況や音声の処理方法はブラウザ・端末の設定に依存します。

### 台帳を使う

1. 画面下部の「1円単位でキチッと管理＆自分で確定申告する（精密台帳を開く）」を開きます。都道府県を選ぶと、国保の概算にその地域の代表的な料率が使われます。初期値は全国平均です。
2. 「入ってきたお金」または「使ったお金」を選び、日付、項目、金額、必要に応じてメモを入力して記帳します。
3. 年度タブで2025年・2026年の集計を切り替え、科目別・月別の集計や仕訳帳を確認します。台帳の集計を診断へ反映するボタン、CSV出力、記録の削除も使えます。

台帳はブラウザのローカルストレージに保存されます。ブラウザのデータ削除や別の端末・ブラウザへの変更で記録を参照できなくなるため、必要に応じてCSVを保管してください。CSVには全年度の記録が出力されます。

診断結果は入力内容と簡略化した前提に基づく**目安**です。国保の実際の金額は市区町村や世帯状況などによって異なります。申告や納付の際は、自治体・税務署などの最新情報を確認してください。

## ローカルで実行する

リポジトリにはブラウザ用のビルド済みファイル `web/dist/` が含まれています。Python 3 があれば、リポジトリのルートで次を実行して [http://localhost:8080](http://localhost:8080) を開けます。

```bash
python3 -m http.server 8080 --directory web
```

## 開発・ビルド

TypeScript を編集した場合は、リポジトリのルートで以下を実行します。Node.js の `module.stripTypeScriptTypes` を使用します（Node.js 25 で動作確認）。

```bash
npm run build
```

`wasm-pack` が利用できる場合、通常のビルドは Rust エンジンの WebAssembly ビルドも試みます。Wasm が読み込めない場合は、ブラウザ内の JavaScript エンジンにフォールバックします。Wasm を明示的にビルドするには、Rust と `wasm-pack` を用意して次を実行します。

```bash
npm run build:wasm
```

Rust のテストは、リポジトリのルートから次のように実行できます。

```bash
cargo test --manifest-path engine/Cargo.toml
```

`npm run build` は `web/dist/` を更新します。GitHub Pages のワークフローは `web/` をそのまま公開するため、フロントエンドを変更した場合はビルド結果もコミットしてください。`main` への push 後、GitHub Actions が Pages にデプロイします。

## 主なファイル

```text
engine/src/             Rust の診断・税金・国保・扶養計算
web/index.html          アプリの画面
web/styles.css          画面のスタイル
web/src/main.ts         画面操作、音声入力、診断・台帳の連携
web/src/voice_parser.ts 音声・テキスト入力の解析
web/src/ledger.ts       台帳の保存、集計、CSV出力
web/src/wasm_bridge.ts  Wasm 読み込みと JavaScript 計算エンジン
web/dist/               ブラウザ用の生成済み JavaScript
scripts/build.mjs       フロントエンドのビルド
.github/workflows/      GitHub Pages のデプロイ設定
```
