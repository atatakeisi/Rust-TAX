# TikTokライバー向け 税金・国保・親の扶養 一撃診断

2025年・2026年の配信収入をもとに、税金、国民健康保険、年金、親の扶養への影響を概算するスマートフォン向けアプリです。日付と金額を記録できる台帳も使えます。

**公開ページ： [https://atatakeisi.github.io/Rust-TAX/](https://atatakeisi.github.io/Rust-TAX/)**

## 使い方

1. 公開ページを開き、マイクボタンから「20歳、去年50万、今年250万、経費30万」のように話します。マイクの使用を求められたら許可してください。例文ボタンや認識テキスト欄への直接入力も使えます。
2. 金額を調整する場合は、マイクの下の「手入力用」を開き、2025年・2026年の振込額と経費をスライダーまたは「−／＋」ボタンで設定します。2025年の開始月や申告状況もここで設定できます。
3. 「身バレ防止プロフィール選択」で年齢区分と給与の有無を選びます。給与がある場合は年間給与額を設定します。
4. 診断結果で白色・青色申告を切り替え、税金や国保、手残り、積立額、親の扶養への影響を確認します。詳細欄には年度別の内訳やアクションが表示されます。「スクショ1画面」や「LINEコピー」も利用できます。

診断結果の「収入から所得を計算する流れ」では、配信の振込と給与の収入合計、それぞれの所得、所得の合計を確認できます。配信は経費と適用される青色申告特別控除を差し引き、給与は給与所得控除を差し引いてから合算します。給与がある場合、表示される所得税・住民税は給与のみの場合と比較して配信により増える分の目安であり、給与分を含む税額の総額ではありません。

音声認識が使えない場合は、画面の案内に従って端末のキーボードの音声入力を使うか、テキスト欄やスライダーで入力してください。音声認識の対応状況や音声の処理方法はブラウザ・端末の設定に依存します。

### 台帳を使う

1. 画面下部の「1円単位でキチッと管理＆自分で確定申告する（精密台帳を開く）」を開きます。都道府県を選ぶと、国保の概算にその地域の代表的な料率が使われます。初期値は全国平均です。
2. 「入ってきたお金」または「使ったお金」を選び、日付、項目、金額、必要に応じてメモを入力して記帳します。
3. 年度タブで2025年・2026年の集計を切り替え、科目別・月別の集計や仕訳帳を確認します。台帳の集計を診断へ反映するボタン、CSV出力、記録の削除も使えます。

台帳はブラウザのローカルストレージに保存されます。ブラウザのデータ削除や別の端末・ブラウザへの変更で記録を参照できなくなるため、必要に応じてCSVを保管してください。CSVには全年度の記録が出力されます。

診断結果は入力内容と簡略化した前提に基づく**目安**です。実際の税額や保険料、申告の要否は所得の区分、控除、加入する保険、自治体や個別の事情などによって異なります。青色申告特別控除の適用には要件があります。申告や納付の前に、税務署・自治体・税理士等にご確認ください。画面にも同じ趣旨の注意書きを表示しています。

## Rust 版の構成

画面の生成・操作、音声認識後のテキスト解析、台帳の保存・集計・CSV生成、税金・扶養診断を Rust / WebAssembly で実行します。既存の台帳保存キーを引き継ぐため、同じ公開URL・ブラウザで利用すれば従来の記録を読み込めます。

HTML は Rust が読み込む画面テンプレート、CSS は表示スタイルとして使用します。JavaScript は Wasm の起動と自動生成されるブラウザ連携コードに使用します。音声認識自体はブラウザの機能です。旧版の `web/src/` と `web/dist/` は移行前の参照用に残してあり、現在の起動処理からは利用しません。

## ローカルで実行する

Rust（rustup）、Node.js、Python 3 を用意し、リポジトリのルートで実行します。

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-pack --version 0.15.1 --locked
npm run build
python3 -m http.server 8080 --directory web
```

[http://localhost:8080](http://localhost:8080) を開いてください。`file://` で直接開くことはできません。Wasm の読み込みが必要です。ローカル導入済みの `.tools/bin/wasm-pack` があれば、ビルドスクリプトはそれを優先します。

## 開発・テスト・公開

Rust の画面コードまたはテンプレートを編集したら `npm run build` で `web/pkg/` を生成し直してください。CSS の変更は再読み込みで反映されます。Wasm ビルドが失敗した場合、ビルドはエラー終了します。

```bash
# Rust の診断エンジンとフロントエンドのテスト
npm test

# Wasm を実行して画面操作を検証（テスト専用の依存ライブラリを導入）
npm ci
npm run test:ui
```

画面操作テストは DOM 模擬環境で動きます。実際の音声認識、端末固有のクリップボード権限、見た目はブラウザでの確認が必要です。

`main` への push 後、GitHub Actions が Rust のテスト、Wasm ビルド、画面操作テストを行って Pages にデプロイします。生成物 `web/pkg/` は Git 管理対象外なので、コミットはソースとロックファイルを含めてください。台帳のCSVには全年度を含むことがわかるファイル名を使用します。

```text
frontend/src/parser.rs         日本語テキストの解析
frontend/src/ledger.rs         台帳データ形式・集計・CSV生成
engine/src/                    Rust の税金・国保・扶養計算
web/index.html                 Wasm の起動と読み込みエラー表示
web/styles.css                 画面のスタイル
web/pkg/                       Rust ビルドで生成される配信用 Wasm
scripts/build.mjs              Rust フロントエンドのビルド
tests/ui.mjs                  Wasm の画面操作テスト
.github/workflows/pages.yml    GitHub Pages のテスト・ビルド・公開
```
